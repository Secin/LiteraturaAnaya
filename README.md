# Descripción del Proyecto
<p align="justify">
Es una Aplicación de Consola java para acceder a la información del servicio de gutendex, servicio que contiene datos de libros y sus autores. La aplicación muestra un menu de opciones númericas por las que podrás acceder a cada funcionalidad
  
</p>

## Funcionalidades
:heavy_check_mark: `Funcionalidade 1:` Bucar Libro por titulo desde el servicio Gutendex y almacenarlo en una Base de datos.

:heavy_check_mark: `Funcionalidade 2:` Mostrar libros buscados.

:heavy_check_mark: `Funcionalidade 3:` Buscar Libro por titulo en la Base de datos

:heavy_check_mark: `Funcionalidade 4:` Listar libros registrados en la base de datos

:heavy_check_mark: `Funcionalidade 4:` Listar libros registrados en la base de datos

:heavy_check_mark: `Funcionalidade 4:` Listar Autores registrados en la base de datos

:heavy_check_mark: `Funcionalidade 4:` Listar los 6 libros más descargados

:heavy_check_mark: `Funcionalidade 4:` Buscar Libro por su idioma

:heavy_check_mark: `Funcionalidade 4:` Listar Autores vivos en un año determinado
